# Arthur — A New Beginning

Pack de desenvolvimento **0.1.0** para Stardew Valley 1.6, SMAPI e Content Patcher.

Arthur tem 20 anos, nasceu na Cidade de Zuzu e trabalha de casa como designer gráfico freelancer. Mudou-se para perto da Vila Pelicanos para encontrar tempo para os amigos e para o jogo independente que está criando. Seu aniversário é **17 da Primavera**. O arco de amizade chega a oito corações. Namoro, casamento e família usam os sistemas nativos do jogo.

O projeto reconstruído mantém quatro mapas, 52 chaves de rotina, 22 eventos e 258 entradas narrativas ou de interação por idioma, em português brasileiro e inglês. O pack só registra Arthur com as duas folhas gráficas-base. O marco de 1.000 diálogos originais e os testes no jogo seguem pendentes.
